Drop per-episode artwork here (e.g. `ep04.jpg`) and reference it from
`src/data/episodes.sample.json` as `"image": "/episodes/ep04.jpg"`. See the
"Add an episode manually" section in the repo root `README.md`.

This folder ships as static files under `/episodes/*` — not to be confused
with the `/episodes` *route*, which is generated from the content collection.
